# Nomen Nescio
[playable game link.](https://requiemsbullet.itch.io/nomen-nescio)
savepoint 2026

Nomen Nescio is a visual novel about a woman named Maria who has been having the same dream for an extended period of time. Though, these nights are different, she is not the only presence.

Use the enter key to continue through dialogue, mouse buttons to click through UI including choice menus. 

All parts of Nomen Nescio were created by @ requiemsbullet.
